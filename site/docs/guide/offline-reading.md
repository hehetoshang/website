# 下载与离线阅读

## 下载一本书

从详情页或书籍快捷菜单选择“下载”。任务会进入下载管理，成功后书籍出现在本地书架。

## 下载管理

“设置 → 下载管理”可以按全部、下载中、已下载、暂停和失败筛选任务，并执行暂停、继续、重试或删除。

![墨客下载管理界面](/screenshots/moke-downloads.png)

*下载管理：集中查看本机离线书籍、任务状态和占用空间。*

关闭应用或网络中断后，未完成任务可能需要在下载管理中继续。

## 进入离线模式

- 在连接页直接选择“进入离线模式”；或
- 在线时从“设置 → 离线书库”进入。

离线模式不会请求 Talebook，只列出当前设备已完成下载的书籍。

## 下载目录

Windows、macOS 和 Linux 可以在设置中选择下载目录。移动平台由系统管理存储位置；Web 预览使用浏览器存储。

## 删除与空间

删除下载只会移除当前设备上的文件和本地记录，不会删除 Talebook 原书。PDF 与含大量图片的 EPUB 可能占用较多空间。

::: warning
不要在系统文件管理器中随意移动单个下载文件，否则墨客的本地记录可能与实际文件不一致。
:::
