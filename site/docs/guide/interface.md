# 认识墨客界面

墨客会根据设备尺寸显示桌面、平板或手机布局，但核心入口保持一致。

![墨客桌面端主界面](/screenshots/moke-interface.png)

*桌面端主界面：侧边栏、书架与应用内容区。*

## 主要入口

| 入口 | 用途 |
| --- | --- |
| 书架 | 查看 Talebook 书架以及已经下载到本机的书籍 |
| 书库 | 浏览全部藏书，按分类、标签、作者等条件筛选 |
| 搜索 | 按书名、作者和简介等元数据查找书籍 |
| 设置 | 管理服务器连接、账户、下载目录、阅读器与显示选项 |
| 我的 | 登录后查看个人资料、阅读记录、下载记录等信息 |

桌面端使用侧边栏导航；手机和平板使用底部标签栏。切换布局不会改变服务器或离线书籍数据。

## 书籍操作

点击书籍进入详情页，可查看封面、作者、简介与可用文件格式，并根据服务器能力选择：

- 在线阅读
- 下载后阅读
- 加入或移出书架

桌面端可使用右键菜单，触屏设备可长按书籍。批量选择模式支持一次处理多本书。

## 在线与离线状态

连接 Talebook 时，书库、搜索和个人数据来自服务器。进入离线模式后，墨客只显示本机已经完整下载的内容，不会尝试调用服务器接口。

当前连接状态与服务器信息可以在“设置 → 连接与数据”中确认。
