# 安装墨客

| 平台 | 安装包 | 最低系统要求 |
| --- | --- | --- |
| Windows | `.msi` / `.exe` | Windows 10 1809+ |
| macOS | `.dmg` | macOS 11+ |
| Linux | `.AppImage` / `.deb` | glibc 2.31+ |
| Android | `.apk` | Android 8+ |
| iPhone / iPad | `.ipa` | iOS / iPadOS 17+ |
| OpenHarmony | `.hap`（Alpha） | HarmonyOS NEXT 5.0+，API 12 |

请从[最新版本页面](https://github.com/talebook/moke/releases/latest)下载安装包，并留意对应版本的发布说明。

::: tip
移动平台的安装方式可能受到系统签名与分发策略限制，请以 Release 中的说明为准。
:::
