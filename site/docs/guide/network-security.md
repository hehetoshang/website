# 网络与安全

墨客既支持公网 HTTPS，也兼容纯 HTTP 局域网与自签名证书，但不同连接方式的安全边界不同。

## 推荐连接方式

| 场景 | 建议 |
| --- | --- |
| 公网访问 | 使用可信 CA 签发的 HTTPS 证书 |
| 家庭局域网 | 优先使用 HTTPS；受控网络可使用 HTTP |
| 自签名证书 | 仅在确认服务器身份后启用兼容选项 |

::: warning
不要在公共 Wi-Fi 或其他不可信网络中通过 HTTP 输入账号、密码或访问码。
:::

## 在线 EPUB 的安全限制

在线阅读需要 Talebook 提供 `talebook.reader.bootstrap.v1` 能力和逐书授权资源。墨客会校验服务器来源、重定向、MIME、Range、ETag 与资源版本：

- 不接受跨服务器书籍资源
- 不把 Cookie 或 Token 写入书籍 URL
- 拒绝异常重定向或资源类型
- 资源版本变化时停止继续读取旧内容

这些校验失败时，应改用“下载后阅读”，不要尝试绕过安全提示。

## 本地数据

下载的书籍和应用设置保存在当前设备。删除本地副本不会删除 Talebook 上的原始书籍；卸载应用前应确认是否需要保留本地内容。
