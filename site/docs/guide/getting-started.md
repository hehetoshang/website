# 快速开始

使用墨客前，需要准备一个可以从当前设备访问的 Talebook 服务。

## 1. 安装墨客

前往 [GitHub Releases](https://github.com/talebook/moke/releases/latest)，根据设备选择安装包。详细要求见[安装墨客](/guide/installation)。

## 2. 准备服务地址

使用浏览器确认 Talebook 可以访问，并记下完整地址，例如：

```text
https://books.example.com
```

局域网服务也可以使用 IP 和端口：

```text
http://192.168.1.20:8080
```

## 3. 连接书库

打开墨客，填写 Talebook 地址。服务启用了访问码时，请同时填写访问码，然后按提示登录或注册。

连接成功后即可浏览书库、在线打开书籍，或把书籍下载到本地书架。
