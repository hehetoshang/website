# 设置与显示

设置页按账户、连接、离线书库、阅读和应用分组。某些选项只在特定平台出现。

## 账户与连接

- 查看当前账户与服务器信息
- 退出账号但保留服务器配置
- 断开当前服务器并返回连接页
- 在线状态下进入离线模式

“退出登录”和“断开连接”用途不同：退出登录只清除账号会话；断开连接会移除当前服务器选择。

## 下载目录

Windows、macOS 和 Linux 桌面端可以选择下载目录，也可恢复应用默认目录。移动端由系统管理存储位置，不能手动选择。

Web 预览模式使用浏览器存储，不等同于正式客户端的文件目录。

## 阅读器

桌面端可选择：

- **内嵌 Readest**：保留墨客内的阅读体验，并支持进度与笔记集成。
- **系统默认应用**：调用系统中的其他阅读器，但不会同步墨客阅读进度和笔记。

## 主题与屏幕模式

“设置 → 主题与显示”提供浅色、深色和跟随系统选项。支持的平台还可启用适合墨水屏的显示模式。

## 更新与应用信息

设置页会显示墨客版本并提供更新检查。关于应用、隐私政策和贡献者信息也从这里进入。
