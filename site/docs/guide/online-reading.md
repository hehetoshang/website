# 在线阅读

墨客内嵌 Readest 阅读器，支持 EPUB、PDF 等格式。具体能力会随平台、格式与版本变化。

## 在线 EPUB

支持的 Talebook 服务器会向墨客声明 `talebook.reader.bootstrap.v1` 能力，并为每本书生成授权资源：

```text
/read/resource/<id>.epub?revision=...
```

墨客按 Range 请求读取当前需要的字节，不会先把整本书写入离线书库。

## 为什么有时不能在线读

墨客会拒绝以下资源：

- 来自另一台服务器的地址
- 异常重定向
- 不正确的 MIME 类型
- 缺少 Range 或 ETag
- 阅读过程中资源版本发生变化
- 登录或逐书授权已经失效

这些情况不是普通格式错误。重试仍失败时，请选择下载后阅读。

## 阅读器选择

桌面端可以在设置中选择内嵌 Readest 或系统默认应用。系统应用不会回传阅读进度与笔记。

## 进度与批注

内嵌阅读器支持阅读进度，并可提供高亮、笔记、书签与章评入口。可用能力取决于格式和当前版本。
