# 关于墨客

墨客（Moke）是面向 [Talebook](https://github.com/talebook/talebook) 的免费开源跨平台电子书客户端。

Talebook 负责管理和提供自托管书库；墨客负责在桌面与移动设备上连接书库；内嵌的 [Readest](https://github.com/hehetoshang/readest-reader) 提供阅读体验。

## 主要能力

- 浏览与搜索 Talebook 书库
- 在线阅读 EPUB、PDF 等格式
- EPUB Range 按需读取
- 下载到本地书架并离线阅读
- 支持访问码、登录与注册
- 兼容自签名 HTTPS 与纯 HTTP 局域网
- 支持 Windows、macOS、Linux、Android、iOS、iPadOS 与 OpenHarmony

源代码、版本发布和问题追踪均位于 [talebook/moke](https://github.com/talebook/moke)。
