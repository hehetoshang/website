# 书库、搜索与书架

![墨客书库界面](/screenshots/moke-library.png)

*书库界面：浏览 Talebook 中的藏书并切换展示方式。*

## 三个入口的区别

| 入口 | 数据范围 | 常见用途 |
| --- | --- | --- |
| 书库 | Talebook 的全部可访问藏书 | 浏览分类、标签、作者和出版商 |
| 搜索 | 当前书库或本地书架 | 按书名、作者、简介等元数据查找 |
| 书架 | 服务器书架或离线书架 | 集中管理想读、在读和已下载书籍 |

## 浏览书库

书库支持封面网格和列表视图。筛选条件来自 Talebook 元数据；服务器没有填写的分类、标签或作者不会凭空出现。

## 操作书籍

- 点击或轻触：进入详情页
- 桌面右键：打开快捷菜单
- 触屏长按：打开快捷菜单
- 选择多本：进入批量模式

详情页会列出可用文件格式，并把“在线阅读”和“下载后阅读”分开显示。

## 服务器书架与离线书架

在线状态下的书架来自 Talebook 账号；离线模式中的书架来自当前设备。二者可能包含不同数量的书。

删除本地下载不会删除服务器原文件；从服务器书架移除也不等于删除书籍。
