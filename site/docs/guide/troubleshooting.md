# 常见问题

建议按“网络 → 认证 → 书籍 → 本地存储”的顺序定位问题。

## 无法连接服务器

1. 在同一设备的浏览器中打开完全相同的地址。
2. 检查 `http://`、`https://`、域名、IP 和端口。
3. 检查 Talebook、反向代理与防火墙。
4. 局域网设备需确认路由器没有启用客户端隔离。

`localhost` 和 `127.0.0.1` 永远指向当前设备；手机不能用它们访问另一台电脑上的 Talebook。

## 反复要求访问码或登录

- 确认访问码仍有效。
- 检查反向代理是否保留 Cookie。
- 检查设备时间是否明显错误。
- 尝试退出登录后重新登录，而不是反复提交同一页面。

## 自签名证书报错

优先换用受信任证书。必须使用自签名证书时，确认连接的是自己的服务器，再启用兼容选项。

## 在线阅读失败

如果详情页仍能下载，但在线阅读提示 Range、ETag、MIME、重定向或授权错误，说明服务器未满足安全在线阅读要求。先尝试下载后阅读，再检查 Talebook 与反向代理版本。

## 下载失败或离线书架为空

- 在下载管理中查看任务状态并重试。
- 检查设备剩余空间。
- 桌面端检查自定义下载目录是否仍可访问。
- 确认书籍已经完整下载，而不是只加入服务器书架。

## 系统默认阅读器没有同步进度

这是预期行为。需要进度和笔记集成时，请在设置中选择内嵌 Readest。

## 仍未解决

前往[反馈问题与贡献](/guide/contributing)，按模板准备版本、平台、复现步骤和脱敏错误信息。
