# 连接 Talebook

## 服务地址

填写可从当前设备访问的 Talebook 根地址，并包含 `http://` 或 `https://`。不要填写后台管理页、单本书或 API 的子路径。

## 访问码与账号

墨客支持 Talebook 的访问码、登录和注册流程。是否允许注册由服务端配置决定。

## 局域网与自签名证书

墨客可以连接纯 HTTP 局域网服务，也支持使用自签名证书的 HTTPS 服务。

::: warning
通过公网访问时应优先使用有效的 HTTPS 证书。纯 HTTP 会明文传输登录信息，不适合不可信网络。
:::

## 连接失败

1. 用同一设备的浏览器访问服务地址。
2. 检查协议、域名、IP 和端口。
3. 检查 Talebook、反向代理和防火墙状态。
4. 自签名证书场景下，确认墨客中的兼容选项。
