# 连接 Talebook

## 地址格式

填写 Talebook 的根地址，不要填写管理后台、书籍详情或 API 子路径。

```text
https://books.example.com
http://192.168.1.100:8080
```

墨客会自动补全未填写的协议，但明确填写协议可以避免连接到错误端口。

## 连接后的流程

墨客首先校验服务器，然后读取欢迎页配置：

1. 服务器要求访问码时，先进入访问码页面。
2. 服务器需要账号时，进入登录页面。
3. 允许注册时，可以从登录页创建账号。
4. 无额外要求时，直接进入书架。

这些规则由 Talebook 服务端决定，墨客不会绕过访问限制。

*服务器启用私人图书馆后，需要先通过访问码验证。*

## 试用演示书库

连接页提供演示地址 `https://demo.talebook.org` 的复制按钮。演示服务只适合体验，不应保存私人数据。

## HTTP、自签名证书与反向代理

- 局域网可以使用纯 HTTP，但不应暴露到不可信公网。
- 自签名 HTTPS 只应在确认服务器身份后使用兼容选项。
- 反向代理必须正确转发认证、Range 与相关响应头。

更多边界见[网络与安全](/guide/network-security)。

## 切换服务器

在“设置 → 连接与数据”中选择“断开连接”，即可返回连接页。断开服务器不会自动删除已经下载的本地书籍。
